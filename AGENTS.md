# Regras de colaboração do projeto

## Preservação de funcionalidades existentes

- Toda nova implementação deve preservar o comportamento, os dados, os assets e as funcionalidades já existentes no aplicativo.
- Não excluir, substituir, renomear ou desativar código, telas, arquivos, registros ou assets existentes como parte de uma nova implementação, salvo quando o usuário autorizar explicitamente essa alteração.
- Antes de alterar uma área existente, verificar seus usos e manter compatibilidade com os fluxos atuais; preferir extensões aditivas e migrações compatíveis.
- Se uma mudança solicitada parecer exigir remoção ou substituição, interromper essa parte e pedir confirmação explícita ao usuário antes de prosseguir.
